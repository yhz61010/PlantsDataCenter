# PlantPlus 使用指南

优先使用中国植物图像库 PlantPlus：https://www.plantplus.cn/cn。

## 文字检索

1. 使用用户提供的中文名、拉丁名、俗名或别名检索。
2. 多个结果时，优先匹配标准中文名和拉丁学名；必要时结合科属、分布、生境判断。
3. 进入详情页后按 Tab 分区提取，不要跨 Tab 混用关键字段来源。
4. 对同名或近名结果保持谨慎，避免把属名、栽培品种或异名误当成目标物种。
5. 输出时保留 PlantPlus 页面链接和检索日期。
6. 如果某些字段来自 PlantPlus 以外的来源，必须在字段正文或元数据中明确标注对应来源。

## PlantPlus Tab 字段来源

- `中文名`：从 `名称分类` Tab 获取，优先使用接受名对应的中文名。
- `学名`：从 `名称分类` Tab 获取，保留拉丁名与命名人，注意大小写和斜体规范。
- `分类系统`：从 `名称分类` Tab 获取；尽量提取界、门、纲、目、科、属完整层级。
- `俗名`：合并两个来源后输出：`植物百科` Tab 页面中的 `俗名`，以及 `名称分类` Tab 下的 `别名`。合并时去重、去空值，保持常用中文名优先。
- `植物志`：从 `植物志` Tab 获取正文。不要显示该 Tab 下第一行题录导航或页码导航，例如 `《中国植物志》 第43(3)卷 (1997) >> 004页 PDF >> 臭椿 Ailanthus altissima`。
- 其他百科字段：描述、物种保护、分类信息、形态特征、生态习性、功用价值优先从 `植物百科` Tab 提取。

## 非 PlantPlus 来源标注

- PlantPlus 来源只指 `https://www.plantplus.cn/` 页面本身，不包括页面外链到 PPBC、WFO、POWO、CFH、GBIF、Baidu、Bing 等站点后的内容。
- 使用外链或备选来源补充时，字段旁或 `元数据` 中必须写明来源名称和链接。
- 不要只写“来源：PlantPlus、WFO、CFH”这类总括列表；应说明哪些字段来自哪个来源。
- 如果某个字段由模型基于已检索特征归纳生成，例如 `一眼分辨法` 或 `相似物种与区分`，标注为“基于已引用形态特征归纳”，并列出依据来源。
- 如果 PlantPlus Tab 因动态加载无法读取完整正文，写明“PlantPlus 页面可访问，但该 Tab 正文未能完整提取”，再说明补充来源。

## 图片识别

1. 优先检查图片是否包含可定种部位：花、果、叶序、叶形、枝条、树皮、全株或生境。
2. 如果可以使用 PlantPlus 图片识别或图像检索，上传图片并记录候选物种和置信度。
3. 不要只按最高候选直接定种；必须用候选物种的形态特征与图片可见特征交叉验证。
4. 低置信度或特征不足时，列出多个候选，并说明需要补拍的部位。

## 信息提取要点

- 学名、中文名、分类系统：只采用 `名称分类` Tab 的信息作为 PlantPlus 主来源。
- 俗名：统合 `植物百科` Tab 的 `俗名` 与 `名称分类` Tab 的 `别名`。
- 植物志：使用 `植物志` Tab 正文，剔除第一行题录导航。
- 形态：优先记录肉眼可见且有鉴别价值的特征。
- 分布：区分自然分布、栽培、逸生和引种。
- 保护：保护等级必须来自权威来源；没有明确记录时写 `暂无数据`。
- 图片：可用作识别依据，但不要把图库照片描述误写成物种唯一特征。

## 未找到结果时

明确写出：

`在中国植物图像库（PlantPlus）未检索到该植物的相关数据。`

随后按顺序检索中国植物志、中国生物物种名录、CFH 中国自然标本馆和其他权威来源，并在元数据中标注替代来源。
